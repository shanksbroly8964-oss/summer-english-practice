# 需求規格卡：發音升級

## 🎯 目標（一段式）
把「暑假英文學習計畫」App 的發音，從「瀏覽器即時朗讀（品質因手機而異）」升級為
**edge-tts 預生成的真人級美式英語 MP3**，全站發音一致，並補上口說跟讀與聽力相關功能。
由多個 OpenCode Agent 平行開發、QA 做 E2E、我派 PM Agent 盯進度，最後產出使用說明書
與兩份 md（重建指南＋操作手冊）。

## ✅ 範圍（已確認）
- **音檔範圍＝全部**：單字、單字例句、文法例句、文章、寫作例句。
- **語音＝美式・女聲為主**（en-US，清晰女聲，貼近國中教科書）。
- **播放架構**：MP3 為主 → 抓不到才退回瀏覽器朗讀（備援）→ 音檔「點到才下載」不打包安裝。
- **加值功能（四項全做）**：
  1. 每個單字/例句提供「慢速＋正常速」兩種音檔。
  2. 一鍵連續播放整課單字/例句。
  3. 「聽音選字」新聽力題型（可納入錯題本）。
  4. 文章逐句朗讀＋高亮跟讀。

## ❓ 假設（黃燈推測，請特別看，錯的話現在改）
- 語音：單字/例句/文法/寫作用 **en-US-AriaNeural**；文章用同一女聲。速度：慢速 `-25%`、正常 `0%`。
- 文章逐句：**每句一個音檔（正常速）**；整篇播放＝依序播各句。文章不做慢速版（控制檔案量）。
- 音檔量：約 **2,100 個 MP3、合計約 40MB**；mono、ffmpeg 壓縮；**不打包進離線快取**，點擊時下載並由瀏覽器/SW 執行期快取。
- 命名：`audio/word/<id>_n.mp3`、`_s.mp3`（slow）；`audio/ex/<id>_n.mp3`；`audio/reading/<articleId>_s<句序>_n.mp3`；另出 `data/audio-manifest.json` 對照表。
- 生成在**本機 build 階段**執行（edge-tts 線上生成一次），產物為靜態檔；**終端使用者不呼叫任何 TTS 服務、無隱私外送**。
- 部署：MP3 一起 commit，部署到 Firebase + GitHub Pages（40MB 對兩者皆在容量內）。
- 沿用慣例：APP_VERSION/CACHE 版本控管；`[hidden]!important`；answer 存全文；Firestore `users/{uid}.summer`。
- 既有「慢速/正常」語速切換鈕改為「切換要播放哪一組 MP3」。

## ❌ 排除項（明確不做）
- VoxCPM 真人克隆／自訂聲線（太慢、非必要）。
- 跟讀錄音對比（本輪未勾選）。
- 英式發音、男聲主軸（本輪選女聲美式）。
- 伺服器端即時 TTS。

## 🚚 執行方式
- OpenCode 多 Agent 平行：①音檔生成管線 ②前端播放模組 ③連續播放 ④聽音選字題型 ⑤逐句高亮跟讀；QA Agent 做 E2E；我派 PM Agent 盯進度與是否照計畫。
- 產物：升級版 App（重部署兩站）＋ 使用說明書 ＋ 重建指南.md ＋ 操作手冊.md。

## 📏 成功標準
- 點單字/例句/文法/文章/寫作的 🔊 都播「真人級 MP3」；抓不到才退回瀏覽器朗讀，不報錯。
- 慢速/正常可切換且各有對應音檔；一鍵連播、聽音選字、逐句高亮跟讀皆可用且進錯題本（聽力題）。
- 兩站上線同版本、既有四站不受影響；QA E2E 全綠。
